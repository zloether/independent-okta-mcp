## Claude Code: models for subagents

For "Working with subagents" in AGENTS.md:

- **Sonnet** for the lower-cost work: tests for an API already written, resource and guide prose, mechanical edits, searches, running checks.
- **Opus** for the work you keep: trust-boundary design, decisions the plan or design doc records, judging review findings. Use Opus too for a subagent whose task needs that judgment, such as a review or a security pass.
